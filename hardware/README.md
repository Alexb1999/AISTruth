# Hardware

Hardware is optional and out of scope for the current cloud-first MVP.

The product path is to consume permitted AIS feeds and GEODNET correction streams from software. A proprietary receiver, owned miner, or coastal base station may become useful later for redundancy, local demos, or cost offsets, but it is not a dependency for the API, scoring engine, or dashboard.

Use this folder for future receiver bills of materials, deployment notes, antenna siting notes, or data-capture procedures.
